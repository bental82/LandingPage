# Working rules

- You may commit and push **without asking**, but **only to the current working branch** (the `-kimi` branch).
- **Never commit to, merge into, or push to `main`** without explicit user approval.
- Keep changes minimal and mobile-first; don't regress desktop.
- `styles.css` is a dead file — never linked. All CSS is inlined in `index.html` (~line 18); edit it there.
- All page copy is Hebrew (RTL).
